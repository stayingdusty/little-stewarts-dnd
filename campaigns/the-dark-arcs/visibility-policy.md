# Visibility policy

The public GitHub Pages site is a player reference. It may contain completed playthrough summaries, player character sheets, player inventories, and facts about locations, NPCs, events, and lore already learned during play.

DM-only content includes future encounters, unrevealed lore, secret motivations, planned twists, hidden maps, and intake evidence that has not been reviewed. DM-only material is excluded during the build; it is never sent to the browser.

Static-site password prompts are not used as a security boundary. A future protected DM portal must authenticate before serving plaintext. Because this repository has historically been public, removing a file from the current branch does not remove it from Git history.
