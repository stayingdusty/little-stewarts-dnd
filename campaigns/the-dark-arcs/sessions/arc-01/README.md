# Arc 1 session intake

For each playthrough, create a chapter folder such as `chapter-10/` containing:

- `intake.json` — session number, evidence files, and visibility.
- `proposed-changes.json` — proposed canon changes with evidence and confidence.
- reviewed notes or transcripts that are safe to retain.

Photos and raw notes remain DM-only until reviewed. Proposed changes do not become canon until their pull request is merged.

The `chapter-*.json` files in this directory are the authoritative structured sources for reviewed playthrough summaries. The knowledge-base build publishes them and renders them through the shared printable playthrough-summary document. Legacy HTML summaries remain in `DND-Source-Docs` as migration evidence; make future summary changes in the structured JSON.

For a character-sheet-only update, record each observed change separately. Include the character ID, field, previous value, proposed value, evidence filename, confidence, and whether Michael has confirmed any ambiguous handwriting.
